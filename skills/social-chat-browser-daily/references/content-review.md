# 内容审核：男性角色主体，排除真人和女性主体

2026-10-23 用户确认，后续社交竞品素材按本规则。适用于视频、图片、插件下载后审核及直接浏览器获取后的审核。新批固定 `scope.content_review_policy.version=male-character-no-real-person-v1`；采集方式不改变内容条件。

| 实际画面 | 决策 |
|---|---|
| 出现任何真人 | exclude；不要求口播，包括剧情、生活、影视/照片、手部和混剪中的短暂真人 |
| 未见真人，男性角色为明确主体 | keep |
| 女性角色为主体 | exclude；不能因界面中存在一个男性头像就保留 |
| 男女混合、主体不明确、无明确男性角色 | review；复核前不进入风格看板、前10%或飞书 |
| 真人与AI无法确认 | review；不得假设为AI通过 |
| 明显动漫、CG或写实AI男性角色 | 按男性主体判断；不因写实外观自动当真人剔除 |

男性角色主体描述素材的主要视觉角色，不据此判断受众是男频还是女频；不按App名称、国家、文案语言或风格标签代替审核。单个男性头像、短暂男性出镜不足以覆盖主要女性内容；配角、界面小头像也不能单独决定主体。男女内容无法稳定判定主次时先review。

视频实际查看既有六帧；六帧是初筛，不保证检出未采样时刻的短暂真人。混剪、片头片尾或转场存疑须补帧/播放原视频复核。图片查看所有原图。保留原有源文件、manifest、截图/看板和SHA256绑定证据。

新版每条审核记录声明 `review_policy=male-character-no-real-person-v1`，并实际记录：

- `checks.real_person_presence`：`present / absent / uncertain`。
- `checks.primary_subject`：`male / female / mixed / none / uncertain`。已经确认真人而提前排除时可不判角色主体。
- `decision` 与实际观察一致；仅 `absent + male` 可keep。`present` 或确定女性主体必须exclude，其余不确定项不得排名。

风格字段仅描述已通过内容审核的角色画风；删除“真人实拍”风格选项。旧版无真人审核、无口播记录或旧风格标签均不能认证本版男性主体规则。

历史scope/完成记录保留原版本，不自动改scope/hash、重排历史前10%、改飞书或重发日报。恢复旧批会明确返回其固定审核版本；执行者须说明它没有自动采用新版，需要改按新标准重审时另取明确授权并保留新旧审核证据。首次创建的后续批次直接采用新版。
