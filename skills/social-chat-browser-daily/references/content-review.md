### 飞书原附件备用来源


- `template-history-fallback/references-*/references.json`记录参考日、产品、系统、记录ID、原件哈希及读取问题。恢复时重新核对该回执引用的媒体哈希后复用。仅当本地审核覆盖及所有所需证据已核验时，才可按原规则确认完整前日比对。

## 按产品俯瞰模板与内容风格联合审核

新批固定dedupe-first-joint-review-v2：第一道先剔除横屏及插件明确重投（原文件显示宽>高，方形保留，尺寸未知暂缓），再对剩余素材做0.9日内及跨日7天去重，再按实际App身份/系统将剩余项并列组织。只在此阶段实际查看一次完整六帧/全部原图，同时填写内容准入、模板判断和通过项风格，不先做内容/风格初筛再单独复看模板。去重代理图不是人工审核证据。验收须覆盖固定队列的每一条，不能把旧审核理由或CLIP分数当作已经联合审核。App ID未知时沿用完整可见名称及系统，不猜身份/合并改名；跨系统或跨产品合并须在本批明确范围内。

一条素材对应一套源/参数/SHA256绑定的六帧和同一份联合审核记录；已有合格证据复用，不重复提取，不为内容/风格/模板拆成三个看图轮次。去重缺封面时可先取3%代理帧；若其提取参数与正式帧一致则纳入同一套并补余下五帧。图片一次检查全部原图。六帧不足、字小或转场漏采时允许有针对性放大/补帧/播放，不能为追求“一次”跳过存疑。

判断以广告骨架为依据：开场钩子和文案功能、镜头顺序、角色动作/互动、分支选择及反馈、产品演示、CTA与结束页。相同顺序/动作/互动仅替换角色外观、肤色、发型或画法的，标注同模板角色变体；不据人物外貌断言真实人种或国籍。对白本地化、横竖版/侧栏包装、同主体段落的长短剪辑、同互动的答案支路另记变体类型，说明实际差异。相同画风、相同品牌结束页、同一角色或泛化题材本身不足以确认同模板；剧情、动作或核心交互不同的保留区别。

固定 `template_review_version=ad-template-review-v1`。逐条记录素材ID、App/系统、实际复核范围、`template_key`、`same_template / distinct / related_not_duplicate / uncertain`、具体镜头/对白依据及实际查看的帧/原图、manifest、对照板SHA256。同组列出全部组员和变体类型；如提供去重代表建议，按展示估值降序和稳定ID并列规则选代表，明确它是建议还是已实际执行。验收核对逐项覆盖、组内身份一致、比较证据存在，不能只填写完成数量。

六帧不足以判断相同剧情/顺序，或文字太小、转场缺失时，放大原帧、补帧或播放原视频后再判断；仍不确定的单列并暂不纳入最终结果，不能仅因CLIP低分当作新模板，也不能因高分或共同版式直接删除。模板待确认与内容审核存疑分开留因。联合审核完成后，合格同模板组内只留最高展示估值者；没有合格代表不回头审前序去重已剔除项补数。四道筛选后全部合格项按估值排序并上传，不截前100/前10%；旧v1按原scope恢复。历史试算、旧内容审核和已入表记录不自动迁移。

确认与前一天同模板，剔除当天项；即使当天展示估值更高，也不替换历史附件或记录。当天组内保留最高估值代表的规则保持。结果记`same_template / distinct / related_not_duplicate / uncertain`，附参考日期、前一天对照素材ID、双方源/帧/对照板哈希及实际结构依据。存疑暂不纳入。前一天无批次、产品覆盖不全、模板未审或证据缺失记pending并披露影响，不能当零历史、猜无重复或宣称已完成；不擅自改与最近有数据日比较。

当天所有已确认模板及因跨日重复剔除项的关联均保存到本批模板记录，供下一天使用，避免只存入表模板导致隔天重复再入选。没有证据的不补造模板。`pre-review`仍只准备封面去重队列；交接scope/任务提示固定这项人工核验要求，不代表已自动完成模板判断。旧scope/已交付结果不自动重算，用户明确要求补做时另留证据。

## 历史及显式浏览器备用：男性主体、排除所有真人

以下严格规则仅适用于其原scope指定的male-character-no-real-person-v1，不覆盖当前插件交接的明确内容口径。

2026-10-23 用户确认，后续社交竞品素材按本规则。适用于视频、图片、插件下载后审核及直接浏览器获取后的审核。新批固定 `scope.content_review_policy.version=male-character-no-real-person-v1`；采集方式不改变内容条件。

| 实际画面 | 决策 |
|---|---|
| 出现任何真人 | exclude；不要求口播，包括剧情、生活、影视/照片、手部和混剪中的短暂真人 |
| 未见真人，男性角色为明确主体 | keep |
| 女性角色为主体 | exclude；不能因界面中存在一个男性头像就保留 |
| 男女混合、主体不明确、无明确男性角色 | review；复核前不进入风格看板、前10%或飞书 |
| 真人与AI无法确认 | review；不得假设为AI通过 |
| 明显动漫、CG或写实AI男性角色 | 按男性主体判断；不因写实外观自动当真人剔除 |

男性角色主体描述素材的主要视觉角色，不据此判断受众是男频还是女频；不按App名称、国家、文案语言或风格标签代替审核。单个男性头像、短暂男性出镜不足以覆盖主要女性内容；配角、界面小头像也不能单独决定主体。男女内容无法稳定判定主次时先review。

视频实际查看既有六帧；六帧是初筛，不保证检出未采样时刻的短暂真人。混剪、片头片尾或转场存疑须补帧/播放原视频复核。图片查看所有原图。保留原有源文件、manifest、截图/看板和SHA256绑定证据。

新版每条审核记录声明 `review_policy=male-character-no-real-person-v1`，并实际记录：

- `checks.real_person_presence`：`present / absent / uncertain`。
- `checks.primary_subject`：`male / female / mixed / none / uncertain`。已经确认真人而提前排除时可不判角色主体。
- `decision` 与实际观察一致；仅 `absent + male` 可keep。`present` 或确定女性主体必须exclude，其余不确定项不得排名。

## 同次审核填写风格标签（2026-10-26 组合命名）

通过本批固定的内容审核后，在同一次实际看图/抽帧时打标。仅保留一个“风格标签”多选字段，不新增国家/画风字段。新批固定 `scope.style_tagging.version=character-style-v2`，记录 `style_tagging_version`、`style_tags` 数组和具体画面依据 `style_reason`。内容准入与风格分类独立，风格规则不改变用户为该批指定的内容条件。

采用地域审美＋画面风格的常用组合，不预设所有地域与画法的笛卡尔积：

| 标签 | 画面依据 |
|---|---|
| 日式漫画 | 日式动画/漫画的人物造型、线稿、平涂或赛璐璐感 |
| 韩式漫画 | 韩式条漫的人物比例、精细线条和柔和渐变上色 |
| 欧美写实 | 欧美审美倾向的写实角色、面部塑形与光影 |
| 东亚写实 | 东亚审美倾向的写实角色；不足以细分日式/韩式时不强行细分 |
| 中式漫画 | 中式人物设计与漫画画法；不能仅因古装、汉字或投放地判定 |
| 欧美卡通 | 明确的欧美卡通造型、比例和概括化表达 |
| 数字插画 | 明确为数字绘画/厚涂角色插画，地域审美不足以稳定细分；不等同于3D |
| 3D角色 | 明确的三维模型渲染观感、体积、材质与空间光照；写实不自动等于3D |
| 混合风格 | 同一素材存在明显不同画法，须说明各段/角色；不用于回避判断 |
| 待确认 | 内容已通过，但画面不足以稳定分类；不能与断言标签同时填写 |

地域词描述视觉审美，不断言人物国籍或素材制作国家；不根据App、字幕、语言或投放地区推断。古装属于题材，实际出现时写入 `style_reason`，不单独作为风格选项。“厚涂／CG风”不再用于新批：实际查看后区分数字插画、3D角色或其他组合，禁止将旧标签机械映射到3D。常用组合之外先用有依据的画法标签或待确认，后续确有素材再扩展，不能临时发明未支持选项。

一个素材可多选确实观察到的风格；排除/内容待复核项不打正式风格标签。风格待确认与内容待复核分开，不能用风格标签绕过本批内容审核。新批缺版本、标签或具体画面依据，非法/重复标签均阻止排名。标签随候选、排名、交付HTML同步；正式写表时沿用“风格标签（多选）”，按需加入实际使用的新选项并逐值读回，保护手动记录和原有选项。

历史 `character-style-v1` 固定八项原选项并由同一校验器验证原版本，不自动改名、迁移或重审；旧scope未声明style_tagging时不追加要求。重标旧批须另有用户授权、实际看图并保留原证据，不修改历史scope/hash。当前10月24/25日已入表标签本次保留原值。
