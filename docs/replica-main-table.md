# 主表独立复刻

图片监听修复：主表“素材类型=图片、复刻需求类型=替换logo”的记录使用现有 Video Lab CLI，固定 GPT Image 2、原尺寸和已认可的 Afizzy 品牌参考图。支持同一行多张图片，先核验全部原图，再逐张提交；全部成品完整解码、尺寸及 SHA256 核验后，一次写回原行“复刻附件”。成品名称含序号，保留逐张原附件/生成 UUID/任务 ID 的对应关系；不走 Replica 视频分析或换人接口。已有复刻附件不覆盖，失败行不自动重跑，生成回执未知只按原 UUID 核对，附件上传或写表未知不重放。技术核验完成保留人工效果验收提示。图片不支持“替换语言”。

图片使用运行机器上官方 `video-lab login` 的独立登录及当前项目，首次执行后固定账号、profile 和项目；不复制 Cookie 或令牌。监听仅处理图片时无需 Replica 网页会话，视频仍在首次真实请求前核验原账号。图片执行断点位于主运行目录 `image-runs/<record_id>/`，与独立 `material-replica` 使用相同契约；派发意图先落盘，再创建任务。部署到其他机器前须在该机器安装并正常登录 Video Lab；本次仅修改修复分支并进行本地离线测试，未部署或启动真实图片任务。

2026-11-05运行修复：查询使用“复刻需求类型不为空”并在本地严格保留受支持动作，避免删除某个下拉选项后整条查询报InvalidFilter；不自动改动表格选项。进度同步一次读取需求快照，只有内容发生变化才重读并写该记录，避免启动时逐行重复查询全部已完成记录。业务派发前的原附件/需求/执行标识校验保持。网页会话失效仍需正常CLI登录，确认原账号后沿旧断点恢复；不得因登录恢复重跑已完成或失败记录。

2026-11-04按用户要求替代需求池方式。入口与结果都在“广大大竞品”主表同一行，每行保留一个需求和一个结果，不创建、关联或写回需求池。

[打开复刻工作台](https://scnmrtumk0zm.feishu.cn/base/Adz4bj9ECaCCJrsgkj7coheYn3c?table=tblwhAqPfQoBXK3Q&view=vewlY9ngR5)。这只是主表的视图。

1. “复刻需求类型”保留单选：替换logo、替换语言。替换logo使用Afizzy默认品牌；**替换语言必定先换Logo，再翻译**，不是独立翻译原片。人物选项未开放。
2. 翻译时先在“复刻目标语言”多选中选齐语言，最后把需求类型设为“替换语言”。选择需求类型即表示提交，监听自动扫描，不需要修改隐藏状态；未选语言、语言未被平台启用时先提示补齐，不上传或生成。不要在领取后追加语言。
3. 只换Logo：上传自动分析→智能Logo→下载核验→同一行复刻附件。替换语言：上传自动分析→智能Logo→核验Logo成品及实际翻译输入→按目标语言翻译→下载核验所有语言视频→一次写回同一行复刻附件。不同视频独立推进，后台负责生成队列。
4. 多语言结果按文件名`原名_translation_ja.mp4`等区分；Logo中间成品只供输入核验，不提前作为翻译最终结果回填。全部附件token、名称和大小读回匹配后，状态改为结果返回。

执行进度和说明单独显示。没有复刻需求的行不会提交；已有复刻附件不会自动覆盖或重新生成。重复扫描同一需求不产生新任务。已领取参数、原附件身份被冻结，清空需求或修改参数后停止新增操作；隐藏状态的变化不阻止处理。上传或生成回执未知只查原ID，明确生成失败不自动重跑；下载及服务临时失败保留断点退避。

用户确认：行已标记失败后保留任务ID和原因，不自动重跑；重新选择需求或重启监听也不重新上传/生成。只有用户明确要求重试时才核对原断点后处理。

原需求池、历史任务与附件保留，旧监听和创建草稿入口关闭；旧按钮、勾选和关联字段在主表默认视图及工作台隐藏，不再由此执行器读取或写入。没有迁移或重跑旧需求。

当前主表受理视频智能Logo及Logo后的多语言翻译。按用户截图及最新要求，翻译显式提交`input=original`、`parts=[text,voice]`及`trim={remove_cta:false,remove_gameplay:false}`：文字与口播都翻译，翻译前不额外去掉品牌片头、CTA或玩法。目标语言沿表格实际选择，不因示例截图切换为韩语。不强制重做、不修改模型/工作区偏好。人物未开放，图片不走视频执行器。

翻译输入必须经过内容核验：下载Logo中间成品，读取任务当前`source_file`并比对精确大小/SHA256和真实视频时长；不一致就停止。不再PUT切换`video_route=source_video`，该路线可能只使用分析认定的剧情部分，与翻译请求的`input=original`含义不同。Logo失败、无结果、输入核验失败均不会继续翻译。语言结果必须同时匹配`text+voice`和`input=original`，不得报告额外裁剪；各语言按任务`video_file`精确关联。下载完整解码后，逐视频与Logo输入对比时长，误差超过0.25秒即需复查，不回填、不自动重新生成。所有语言合格后才一次写回；附件上传、写表未知仍只读核对。

2026-11-04旧参数实测曾返回5秒日语片段，而Logo输入有28.4秒；服务端标completed但整片验收未通过。核对当前公开前端后确认，网页完整原视频选项直接POST`input=original`，旧CLI漏传该字段且PUT选择了剧情路线，结果标`input=swap`。新参数经过离线契约/恢复/时长测试，并在用户明确授权后完成一次28.4秒日语文字＋配音实测，输入输出等长且完整解码通过；仍保留平台66条文字复查提示，不代表逐帧人工效果验收。旧失败和未知任务不会自动按新参数重跑。

配置`config/replica_main_table.json`固定主表、字段ID、原账号与需求类型触发条件，没有需求池目标。独立运行目录`data/replica-main-table-worker`。本机监听每轮空闲15秒，实际周期包括请求耗时，Mac睡眠或退出进程后不监听。
