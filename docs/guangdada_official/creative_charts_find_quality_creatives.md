# 通过“创意榜单”寻找优质创意

来源：<https://pcntc2tqb4rg.feishu.cn/wiki/B4M1wvysyiC9UIkOpAuckbtJn8b>

最近修改：2025-10-27

相关广大大·创意功能：展示广告、创意榜单、搜索、Tik Tok 精选。

## 一、每周热门榜：每周刚被打上 Top 标签的创意榜单

每周热门榜展示每周新打上 Top1%、Top10% 标签的创意，用于定位每周表现最佳创意。

- 每周热门榜按照创意每周人气值总和排序。
- 该榜单包含所有新投创意以及历史重投创意。

### 榜单数据说明

- 本榜单展示的是每周新被打上 Top1%、Top10% 的创意。系统每个自然周会更新一次创意的 Top 标签；如需查看不同时间段被打上 Top 标签的创意，需要选择不同周期。
- 周总人气值：所选时间段内，创意每天的人气值总和。
- 时间选择范围：榜单支持查看最近 7 周的数据。

### 如何在每周热门榜中找到想要的优质创意

示例目标：查看 2025-10-20 至 2025-10-26 这个自然周内，工具行业“AI 生成式人工智能”分类中，刚被打上 Top1% 标签的创意；去掉 Top10% 创意，并且只看新投创意，去掉历史重投创意。

操作口径：

- 时间周期选择：2025-10-20 至 2025-10-26。
- 进入工具行业分类，选择“生成式人工智能”。
- 在全部 Top 创意中仅勾选“仅看人气值 Top1%”。
- 勾选“去掉重投广告”，即只看新广告。
- 所有筛选条件都勾选后，榜单列表中的结果即为目标结果。
- 查看榜单时，如果看到感兴趣的广告主，可点击列表中的“仅查看该广告主”按钮，列表会展示该广告主的全部上榜创意，便于深入做竞品素材分析；返回全部结果时点击“取消仅看”。

## 二、每周飙升榜：针对快速起量创意的榜单

每周飙升榜展示每周人气值增长最快的创意，用于快速找到飙升最快的起量广告。

- 每周飙升榜可按照周人气值增量与周人气值增长率排序。
- 该榜单包含所有新投创意以及历史重投创意。

### 榜单数据说明

- 周人气值增量：所选这一周，创意的本周人气值总和相比于上周人气值总和的差值。
- 周人气值增长变化率：所选这一周，创意的周日均人气值相对上周日均人气值的增长变化率。
- 计算公式：`{(本周总人气值 / 7 天) - (上周总人气值 / 7 天)} / (上周总人气值 / 7 天)`。
- 时间选择范围：榜单支持查看最近 7 周的数据。

### 如何在飙升榜中找到想要的优质创意

示例目标：查看 2025-09-29 至 2025-10-05 这个自然周内，益智解谜类游戏 iOS 广告主投放到全部热门地区、YouTube 渠道的起量视频新广告。

操作口径：

- 时间周期选择：2025-09-29 至 2025-10-05。
- 游戏分类选择“益智解谜”大类。
- 渠道仅勾选 YouTube。
- 系统勾选 iOS。
- 国家地区选择全部“热门”地区。
- 图片和视频筛选项仅勾选“视频”。
- 勾选“去掉重投广告”，即只看新广告。

## 三、新创意榜：针对新投创意的榜单

新创意榜根据所选时间段内最新发现广告创意的人气值排序，用于快速找到热门新广告。

- 新创意榜按照创意每周人气值总和排序。
- 只展示所选周期内发现的新投广告，去掉重投广告，重点是发现“新”优质创意。

### 榜单数据说明

- 周总人气值：所选时间段内，创意每天的人气值总和。
- 时间选择范围：榜单支持查看最近 7 周的数据。

### 如何在新创意榜中找到想要的优质创意

示例目标：查看 2025-09-29 至 2025-10-05 这个自然周内，小说品类投放效果最好的新广告；渠道不限，投放地区限定在港澳台。

操作口径：

- 时间周期选择：2025-09-29 至 2025-10-05。
- 行业切换到工具，在工具分类中找到“图书与工具书”，并仅选择“小说”。
- 国家地区选择“港澳台”。
